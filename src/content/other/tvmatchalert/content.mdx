# TV Match Alert

An Android TV application built with **Kotlin**, **Jetpack Compose**, and **Socket.IO** that keeps football fans informed without interrupting their viewing experience.

TV Match Alert allows users to follow their favorite Premier League teams and receive small overlay notifications whenever a selected match begins or resumes after halftime—even while watching Netflix, YouTube, or external HDMI sources.

---

# Overview

TV Match Alert was designed to solve a common problem for football fans: missing kickoff while watching other content on their television.

Rather than requiring users to constantly check scores or switch between apps, the application displays lightweight overlay notifications directly over the current screen whenever an important match event occurs.

The Android TV client communicates with a custom Node.js backend through Socket.IO to receive real-time notifications while maintaining a simple and responsive user experience.

# Features

## Team Selection

Users can choose the Premier League clubs they wish to follow.

- Team selection interface

- Quick updates to followed teams

---

## Real-Time Notifications

Receive notifications when important match events occur.

Current supported events:

- Match kickoff
- Second-half kickoff

Notifications appear as small overlay cards that automatically disappear after five seconds.

---

## Overlay System

Unlike standard Android notifications, TV Match Alert displays notifications over virtually any content.

Supported scenarios include:

- Netflix
- YouTube
- Disney+
- HDMI inputs
- Live TV

The overlay remains unobtrusive while ensuring users never miss important match events.

---

## Background Tracking

The application continues listening for match events even when running in the background.

Features include:

- Foreground service
- Automatic Socket.IO reconnection
- Lightweight background processing

# Application Architecture

```text
Android TV Application
          │
          ▼
Socket.IO Client
          │
          ▼
TV Match Alert Backend
          │
          ▼
Football Data API
```

The architecture separates the Android client from backend scheduling logic, allowing the television application to remain lightweight while receiving live notifications.

---

# User Flow

1. Select teams to follow.
2. Team selections are stored locally.
3. The application connects to the backend using Socket.IO.
4. When a scheduled match event occurs, an overlay notification appears.
5. The notification automatically dismisses after five seconds.
