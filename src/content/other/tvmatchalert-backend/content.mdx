# TV Match Alert Backend

A Node.js backend responsible for scheduling football match notifications and delivering them to connected Android TV devices in real time.

Rather than continuously polling live matches, the backend minimizes API usage by retrieving fixtures once each day and scheduling notifications locally.

---

# Overview

The TV Match Alert Backend powers the Android TV application by coordinating football match schedules and delivering real-time notifications through Socket.IO.

The system was designed with API efficiency as a primary objective, ensuring the application remains compatible with free API usage limits while still providing timely notifications.

Instead of checking every match continuously, the backend intelligently schedules notifications based on each day's fixtures.

---

# Features

## Daily Fixture Scheduling

Each day the backend:

- Retrieves today's fixtures
- Identifies watched teams
- Creates notification schedules
- Avoids unnecessary API requests

---

## Real-Time Communication

Connected Android TV devices receive notifications instantly using Socket.IO.

Supported events include:

- Match kickoff
- Second-half kickoff

---

## Smart Team Tracking

The backend only tracks fixtures involving teams selected by connected users.

Benefits include:

- Reduced API usage
- Lower server workload
- Faster scheduling

---

## Multi-Device Support

Multiple Android TV devices can connect simultaneously.

Each client receives notifications relevant to its selected teams.

```text

      │

      ▼
Node.js Backend
      │
      ▼
Football API
```

The backend acts as an event scheduler between football data providers and connected Android TV clients.

---

# Notification Workflow

1. Android TV connects to the backend.
2. User selects favorite teams.
3. Team subscriptions are stored in memory.
4. A daily scheduler retrieves fixtures.
5. Matches involving selected teams are scheduled.
6. Kickoff notifications are emitted.
7. After approximately one hour, the backend checks match status every two minutes.
8. When the second half begins, another notification is sent.

---

# API Optimization Strategy

A major engineering objective was minimizing Football API usage.

Instead of continuously polling:

```text
00:00
│
├── Retrieve today's fixtures
│
├── Any watched teams playing?
│       │
│       ├── No → Stop
│       │
│       └── Yes
│
├── Schedule kickoff timers
│
├── Send kickoff notification
│
└── After 60 minutes
        │
        └── Check every 2 minutes until second half begins
```

This scheduling strategy dramatically reduces unnecessary API requests while maintaining accurate notifications.
